# Guia da Pasta Journals (Diário de Lee Sanghyeok)
#
# Cada capítulo possui seu arquivo de texto correspondente:
# - chapter1.txt até chapter7.txt : entradas base de cada dia no diário
# - chapter5.txt : inclui também o texto pré-preenchido e digitado automaticamente
# - addendums.txt : atualizações adicionadas ao diário durante o decorrer dos capítulos 6 e 7
#
# Campos suportados:
# - id: identificador da entrada (ex: j1, j2, j3, j4, j5, j6, j7)
# - chapter: número do capítulo (1 a 7)
# - title: título exibido no diário
# - date: data exibida (ex: Thursday, Oct 22)
# - mood: humor de Sanghyeok (Focused, Alert, Tense, Urgent, Cautious, Guarded, Shaken)
# - body: texto principal da reflexão
# - prefilledText: (apenas Ch 5) texto que já aparece digitado
# - typedText: (apenas Ch 5) texto que Sanghyeok digita na animação
